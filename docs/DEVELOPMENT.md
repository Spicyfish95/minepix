# 开发与验证

## 环境与命令

Windows x64、Node.js 24、Rust stable MSVC、C++ Build Tools、Windows SDK、WebView2 Runtime。环境脚本优先使用系统工具链。

在仓库根目录执行：

```powershell
npm ci
npm run desktop
```

`npm run desktop` 启动桌面应用和前端开发服务；`npm run dev` 仅启动前端服务。

```powershell
# 前端构建
npm run build

# 生成签名桌面安装包，需先配置签名环境变量
npm run package
```

安装包位于 `src-tauri/target/release/bundle/nsis/`。签名配置和标签发布步骤见[发布指南](RELEASING.md)。私钥保存在用户 `.ssh` 目录，不复制到工作区，不提交 Git。

## 定向测试

每次改动先记录范围并运行相关测试，跨模块影响或相关失败时再扩大回归。不因文档修改重跑绘画、安装或长时间观察。

正式版 2.0.0 发布范围：同步五处应用版本、变更记录及下载说明，区分正式版 Latest 与预发布标记；保留仅标签触发的完整 CI、固定公钥与版本绑定校验。发布前定向运行发布协议测试和仓库检查；标签流水线执行配置中的完整回归与签名构建。按用户最新要求，本次发布后仅核验公开 Release、实际下载哈希、签名文件及 tauri-latest 频道，不运行本机安装或更新测试；签名真实性及版本绑定由 CI 的固定公钥 Rust 校验器验证。运行结果在取得真实证据后补充，不将准备状态写为已通过。

发布前本地结果：发布协议与公开下载专项 8/8 通过，339 个文本文件、71 个本地链接及 584 个模块引用检查通过，发布脚本语法和 Git diff 空白检查通过。版本与发布配置准备完成，远程标签构建及公开发布结果仍待执行。



完整回归入口为 `npm test` 与 `npm run test:backend`。`npm test` 的前置步骤会构建上述工具。CI 仅在推送 `tauri-v*` 标签时执行完整回归、前端构建及签名发布；普通 main 推送和 PR 不运行 Actions。日常提交需在本地完成相关定向验证。
