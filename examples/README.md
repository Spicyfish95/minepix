# 示例作品

这些作品用于体验编辑器，也是 README 和使用指南截图中的示例。建议先通过“文件 → 保存 → 另存为”保存自己的副本。

| 示例 | 可体验的内容 |
| --- | --- |
| [mushroom.pix](mushroom.pix) | “林间微光”两层、四帧动画，可尝试改色、调整图层或添加帧 |
| [reference-board.pix](reference-board.pix) | 同一作品附带角色与配色参考，体验参考板移动、缩放及取色 |
| [dirt-corners.pix](dirt-corners.pix) | dirt.ase 按 32×32 切块的泥土地形，15 种非空角位组合、自动标注规则及 50 格匹配角预览 |

PIX 是可继续编辑的二进制项目，分享图片时使用“文件 → 导出”。详细步骤见[使用指南](../docs/USER_GUIDE.md)。

固定测试样例位于 tests/fixtures，不进入运行时资源。
